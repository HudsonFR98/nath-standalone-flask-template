{{ _('Async Tasks') }}

{{ _('Background work runs inside the app process with APScheduler (lib/task_scheduler.py), not a separate worker container.') }}

  • {{ _('The scheduler starts when the Flask app loads; jobs are registered with register_task or the @scheduled_task decorator.') }}
  • {{ _('Cron schedules and metadata live in the scheduled_tasks table; each run is logged in task_executions (status, duration, errors).') }}
  • {{ _('Built-in job: database_backup runs daily at 04:00 (cron 0 4 * * *), creates a SQL backup and prunes backups older than seven days.') }}
  • {{ _('Failed runs can trigger a Telegram alert when TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID are set.') }}
  • {{ _('Admins can inspect schedules and history under Admin → Async Tasks.') }}

{{ _('Add a new recurring task: define a function, decorate it with @scheduled_task with a cron expression, and restart the app so registration runs. Use the same pattern as database_backup in task_scheduler.py.') }}

{{ _('Deployment') }}

{{ _('GitLab CI stages: docker → integration → validation → prod. Each deployed environment gets its own VM (Terraform + Pi-hole DNS + Ansible).') }}

  • {{ _('integration: create VM, deploy, run pytest in the container, destroy VM (unless INTEGRATION_KEEP_VM=true).') }}
